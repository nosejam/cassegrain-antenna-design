PROFILE FUNCTIONS

Polynomial interchange

Export both surfaces as zlocal(u) = a₀ + a₁u + a₂u² + …, with u = (r − rOrigin) / rScale. Files include units, radial domains, aperture offsets, axis rotations, and feed location. Conic secondary fits are approximations; error below is measured over each exported domain. 


            

              
              

                
              

            

            

              Import or edit polynomial functions
              

                Load the current profiles as a starting point, then edit the
                JSON. Each surface accepts either
                coefficients: [a₀, a₁, …] or
                expression: "6.54 + 0.22*u^2". Use
                u = (r − rOrigin)/rScale; set rOrigin = 0 and
                rScale = 1 to use the physical radius directly. Use explicit
                multiplication. No code is executed.
              

              

                Import preserves arbitrary polynomial profiles rather than
                forcing them into a conic. The main axis must face +z. Optical
                validity is not established by import; ideal conic rays and
                conic-only quantities are unavailable.
              

              
              
              

                
              

              
              

            

          

        

      

      

        

          
BEHIND THE DESIGN

          
Equations with a traceable source.

          

            Translated from GRANET.FOR and
            GRANEOC.FOR: Christophe Granet’s
            dual-reflector equations, implemented in Fortran by T. A. Milligan.
            Includes 21 symmetric routines and all five open-Cassegrain input
            combinations.
          

          

            Other classical offset, Dragonian, displaced-axis, and Schwarzschild
            source families remain unported. Gain analysis is a separate scalar
            aperture approximation; the Fortran programs supply geometry only.
          

        

        

          

            Coordinates & surface equations
            

              The parent main vertex is at z = 0; the beam points along +z. In
              symmetric designs, the feed is at z = LM and main focus at z = FM.
            

            

              Main: z = r² / (4 FM)
Symmetric secondary: z = LM + c + a √(1
              − σ r² / b²)
b² = σ(a² − c²),   c = FS
σ = −1
              Cassegrain, +1 Gregorian
            

            

              In open-Cassegrain, the main aperture is offset by H. The
              secondary uses a local axis rotated by 180° − THO about the main
              focus, and zLocal = c − a√(1 + r²/(c² − a²)). The feed is 2c along
              that axis. Imported polynomials retain their own local placement.
            

          

          

            Open-Cassegrain source correction
            

              GRANEOC.FOR reports ASR using a cosine denominator. That value
              equals (c/e) tan(TE), contradicting its reported half focal
              separation c and eccentricity e. This app retains ASR as “legacy
              ASR” but draws and exports the consistent hyperbola with a = c/e.
              Surface normals, edge-ray mapping, and equal optical paths are
              independently checked.
            

            

              Bracketed double-precision solving replaces the source’s coarse
              root search. Input combinations follow the same geometric
              equations, so values may differ from the legacy output’s finite
              root tolerance.
            

          

          

            Optical and gain-model limits
            

              Geometry rays are ideal constructions, with no supports, hardware
              intersections, or polarization. Imported polynomial shapes are
              displayed without claiming that they collimate. The pattern panel
              uses a specified Gaussian, flat-phase circular aperture and
              optional central obstruction; it does not solve arbitrary profiles
              for their electromagnetic field.
            

            

              Only forward main-beam/sidelobe estimates are shown (up to ±30°),
              for apertures at least 10 wavelengths across. Efficiency is an
              assumption, not a measured quantity. There is no cross-polar,
              rear-lobe, near-field, feed-pattern, surface-tolerance, or
              full-wave analysis.
